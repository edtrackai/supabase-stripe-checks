# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x (latest) | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Please email **edtrackai@gmail.com** with a description, steps to reproduce, and the affected version. Please don't open a public issue for security reports.

We aim to acknowledge reports within 5 working days and to keep you updated while we look into it. This is a best-effort target, not a guarantee.
